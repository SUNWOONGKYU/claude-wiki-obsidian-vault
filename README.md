# 지축신 (知蓄神) — LLM-Wiki 지식 축적 시스템

Claude Code로 일하면 그 기록이 저절로 지식으로 쌓이고, 다음 작업이 그 지식을 근거와 함께 꺼내 쓰게 만드는 훅 모음이다.

사람이 정리하지 않는다. 항목마다 승인을 요구하지도 않는다. 정상 항목은 자동으로 반영되고, 근거 대조에 실패한 항목만 미확정으로 격리돼 다음 회차에 다시 검토된다.

## 무엇을 하나

작업 대화가 끝날 때마다 여섯 단계가 돈다.

| 단계 | 하는 일 | 산출물 |
|---|---|---|
| 1 원본 수집 | 세션 종료 시 대화 원본을 그대로 저장한다 | `sessions/raw/` |
| 2 1차 증류 | 원본을 읽어 이어가기 요약과 위키 노트로 줄인다 | `sessions/summary/` · `sessions/wiki/` |
| 3 색인 | 언제 무엇을 했는지 찾아 들어가는 목록을 갱신한다 | `sessions/wiki/INDEX.md` |
| 4 2차 증류 | 여러 세션을 가로질러 결정·패턴·함정으로 다시 묶는다 | `sessions/topics/` |
| 5 구조화 | 옵시디언 볼트로 엮는다 (선택) | 이 스킬의 SKILL.md |
| 6 활용 | 검색 대상 묶음을 만들고, 새 세션 시작 때 직전 맥락을 자동 주입한다 | `sessions/corpus.jsonl` |

기록은 **작업 폴더 기준**으로 쌓인다. git 저장소 안에서 실행하면 그 저장소 루트가 기준이 된다. 시스템 폴더(Windows·Program Files 등)에서 실행된 세션은 기록하지 않는다.

## 근거가 어긋나지 않게 하는 장치

2차 증류는 AI가 노트를 재구성하는 단계라 근거가 틀어지기 쉽다. 세 가지를 코드로 막는다.

- **파일명을 AI가 쓰지 않는다.** 원문에 `[S1]` `[S2]` 슬롯 번호만 붙여 주고 그 번호로만 인용하게 한다. 실제 파일명은 프로그램이 대응시킨다. 파일명을 줄여 쓰거나 지어내서 링크가 깨지는 일이 생기지 않는다.
- **작성과 검증을 분리한다.** 작성이 끝나면 별도 호출이 각 항목과 그 항목이 인용한 원문만 놓고 대조한다. 관련성, 숫자·날짜·주체·조건, 제안을 확정으로 바꿔 썼는지를 본다.
- **실패는 격리한다.** 검증에 실패하면 최대 2회까지 다시 쓰고, 그래도 통과하지 못한 항목은 `topics/_미확정.md`로 뺀다. 미확정 항목은 검색 대상에서 제외돼 다음 답변의 근거로 쓰이지 않는다.

주제 노트를 덮어쓰기 전에 이전본을 `topics/_history/`에 남긴다. 잘못된 갱신은 되돌릴 수 있다.

## 설치

필요한 것: **Windows** · **Node.js** · **Claude Code CLI**(구독 로그인 상태). API 키는 쓰지 않는다. 증류는 구독 세션으로 돈다.

```
git clone https://github.com/SUNWOONGKYU/knowledge-accumulation.git
cd knowledge-accumulation
node scripts/install.js
```

설치 스크립트는 `~/.claude/hooks/`에 파일을 복사하고 `~/.claude/settings.json`에 **필요한 항목만 추가**한다. 기존 훅 설정은 지우지 않고, 이미 등록된 항목은 다시 넣지 않는다. 설정은 수정 전에 백업된다.

Claude Code에 그대로 넘겨도 된다.

```
https://github.com/SUNWOONGKYU/knowledge-accumulation 를 clone 하고 README를 따라 설치한 뒤,
node scripts/install.js --check 로 설치 상태를 확인해줘.
```

## 설치 확인

```
node scripts/install.js --check
```

훅 파일과 등록 상태가 항목별로 표시된다. 전부 `O`면 설치가 끝난 것이다.

그다음 **작업 대화를 한 번 끝내면** 작업 폴더 아래에 `sessions/raw/`와 `sessions/wiki/`가 생긴다. 파일이 생겼는지가 아니라 **새 대화에서 이전 결정의 이유를 물었을 때 근거와 함께 답이 오는지**가 실제 확인 기준이다.

## 2차 증류를 언제 도나

세션이 끝날 때마다 미처리 노트를 세어 5개 이상이면 자동으로 돈다. 즉시 돌리려면 이렇게 한다.

```
node ~/.claude/hooks/wiki-topic-distill.js "<작업폴더>" --force
```

매일 한 번 돌게 하려면 작업 스케줄러에 `wiki-daily-run.js`를 등록한다. 등록된 작업 폴더 목록은 세션이 실제로 열린 곳만 자동으로 쌓인다.

## 제거

```
node scripts/install.js --uninstall
```

훅 등록만 해제한다. 훅 파일과 이미 쌓인 기록은 지우지 않는다.

## 확인한 환경과 한계

- 확인한 환경: Windows 11 · Node.js 24 · Claude Code CLI 구독 로그인
- macOS·Linux는 확인하지 않았다. 경로 처리는 OS 중립으로 썼지만 작업 스케줄러 등록 절차는 Windows 기준이다.
- 벡터 검색은 넣지 않았다. 제목·요약·태그와 링크만으로 찾는다. 자료가 늘어 부족해지면 그때 얹을 자리를 남겨두었다.
- 증류는 Claude Code 구독 세션을 소모한다. 한도가 소진되면 저장을 보류하고 다음 회차에 다시 시도한다. 실패한 회차의 기록이 유실되지는 않는다.
